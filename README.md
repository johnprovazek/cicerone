# cicerone

## Description

This project is a website to help with studying for the [Certified Cicerone](https://www.cicerone.org/us-en/certifications/certified-cicerone) exam.
It is based on the [Certified Cicerone Syllabus (V6)](https://www.cicerone.org/sites/default/files/resources/US_English_CC_Syllabus_V6.0.pdf) and the [2021 BJCP Beer Style Guidelines](https://www.bjcp.org/wp-content/uploads/2025/02/2021_Guidelines_Beer_1.25.pdf).
This project can be accessed at [johnprovazek.com/cicerone](https://www.johnprovazek.com/cicerone/).

Developed using React, Chakra UI, and Vite.

## Usage

Test your exam readiness with study questions cycling through beer styles.
Open the settings panel to tailor your study session by selecting specific study fields and beer styles.
